# 附录 C　压测基线数据模板

> **用途**：上线前填写、验收时比对。**"有基线"才叫可观测，没有基线的"正常"是运气。**
> 本模板字段与第 13、14 章一致，可直接打印成表带到机房。

---

## C.0 填写须知（先读）

1. **每个数都要带三件套：单位 + 口径 + 测量方法。** 缺一件，验收时就会各说各话（第 13 章 13.1）。
2. **`#wrong = 0` 是正确性硬判据**，比带宽更硬；不为零即视为"未通过"。
3. **每项至少 5 轮，取中位数，并记录变异度**；变异度 ≤ 5% 才算稳定。
4. **RDMA 打流必须双向**（write + read），读路径与写路径的问题不通用。
5. 所有数字标注来源：【实测】/【原厂】/【推算】/【待实测】。

**口径换算（必记）**：

```
busbw = algbw × 2(n − 1) / n        （n = rank 数 = 卡数）
单卡物理上限 = 400 Gb/s ÷ 8 = 50 GB/s 线速
```

**规模覆盖（逐级都要过，不能只测一种）**：2 / 4 / 8 / 16 / 32 / 96 台。
**原语覆盖**：AllReduce、AllGather、ReduceScatter、AllToAll（终态 768 卡全量）。

## C.4 光链路与 FEC 基线表（第 4、13 章共用）

| 链路编号 | 发送光功率 | 接收光功率 | 余量 | 插损 | `rx_uncorrectable` | 端面检测 | 结论 |
|---|---|---|---|---|---|---|---|
| | | | ≥ 3 dB 为合格 | | **必须 = 0** | 合格/不合格 | |

**判据**：

- 接收光功率落在模块规格窗口内，且**留 ≥ 3 dB 余量**；
- **`rx_uncorrectable = 0`**（硬判据）—— **DDM 光功率正常 ≠ 链路健康**；
- 端面显微镜：无可见划痕 / 污渍 / 裂纹。

**插损分布统计**（属于 O-05 待补项）：记录 **P50 / P95 / 异常点**。

## C.6 交换机与网卡计数器基线表（第 14 章）

| 计数器 | 采集方式 | 正常区间 | 告警阈值 | 责任人 |
|---|---|---|---|---|
| PFC pause（收 / 发） | gNMI / Streaming Telemetry | **偶发 ≠ 0 属正常** | **持续增长**才告警 | |
| ECN 标记数 | 同上 | 低频 | 陡增告警 | |
| 端口丢包 | 同上 | 0 | > 0 持续告警 | |
| FEC `rx_uncorrectable` | 同上 | 0 | > 0 立即告警 | |
| 光功率（DDM） | SNMP / gNMI | 规格窗口内 | 越界或趋势下滑 | |
| 网卡 drop / pause | DCGM / ethtool | 0 | 增长告警 | |

> **"什么算正常"比阈值本身更重要。** PFC pause 偶发不为零是**设计行为**（拥塞反压），
> 只有**持续增长**才是问题。每条指标都必须有**责任人**——没有责任人的指标等于没有指标。
